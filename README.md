# 狼人杀模拟器 (Werewolf Simulator)

使用蒙特卡洛方法模拟狼人杀游戏，旨在测试在特定的AI策略（例如狼人全员倒钩、好人盲目跟随）下，各个阵营的胜率。

## 1. 核心模块与文件结构 (文件说明)

项目代码位于 `src/werewolf/` 目录下，采用了模块化的面向对象设计，将“玩家”、“角色（技能）”和“策略（大脑）”进行了解耦。

### 核心引擎
* **`game/game.py`**: 游戏引擎核心。负责推进游戏阶段（夜晚行动、白天竞选、白天发言、放逐投票、结算死亡与警徽移交）。它协调所有的玩家行为，但不包含具体的玩家AI逻辑。
* **`simulator.py`**: 蒙特卡洛模拟器。负责批量运行多局游戏，统计各个阵营的胜率。
* **`constants.py`**: 游戏里的枚举常量，如阵营（狼人、神职、平民）、角色类型、游戏阶段（夜晚、发言、投票等）。

### 玩家与策略系统 (大脑)
* **`player/player.py`**: 玩家实体类。包含玩家的ID、当前身份（Role）、策略大脑（Strategy）、存活状态，以及个人的**认知状态记录（`belief_state`）**。
* **`player/strategy.py`**: 策略基类（接口定义）。规定了玩家在每个环节可以做的决策方法（如 `act_night`, `vote_day_strategy`, `speech_day_strategy`，以及信息处理钩子如 `update_belief_after_speech` 等）。
* **`player/strategies/base_strategies.py`**: 基础策略（`BasicStrategy`）。实现了所有好人通用的基础逻辑，比如：解析别人的发言（金水、银水、查杀、警徽流）、处理警徽移交逻辑、以及基础的投票顺位（优先跟随预言家 > 其次女巫 > 其次警长）。
* **`player/strategies/*_strategies.py`**: 各种角色的专属策略实现（大脑）。例如 `seer_strategies.py` 规定了预言家怎么发警徽流，`werewolf_strategies.py` 规定了狼人夜晚怎么按优先级刀人等。

### 角色属性与技能系统 (身体)
* **`roles/base.py`**: 角色基类。定义了阵营、夜晚行动优先级。
* **`roles/*.py`**: 各个角色的具体属性和结算逻辑。例如 `witch.py` 记录了女巫的双药状态，并在 `perform_night_action` 中与游戏引擎交互。

## 2. 文件间的依赖关系

项目的依赖流向非常清晰：

1. **Simulator (运行侧)** -> 依赖 `game.py` 初始化并运行游戏。
2. **Game (引擎侧)** -> 依赖 `player.py` 和 `roles/`。引擎按阶段遍历 `Player` 列表，调用 `Player` 的方法，并处理 `Role` 的技能反馈。
3. **Player (实体侧)** -> 依赖 `Role`（提供技能约束）和 `Strategy`（提供决策逻辑）。`Player` 本身不写死任何AI逻辑，全权委托给 `Strategy` 执行。
4. **Strategies (大脑侧)** -> 依赖 `game.py` 的读取接口（获取场上存活玩家列表、当前警长等）以作出决策。各种专属 Strategy 均继承自 `base_strategies.py`，复用基础的信息解析能力。

## 3. 如何使用本项目

本项目使用 `uv` 进行环境和依赖管理。

### 运行批量模拟
如果你想运行蒙特卡洛模拟来查看大样本下的胜率统计：
```bash
uv run python main.py
```
*在 `main.py` 中可以修改循环次数来调整模拟局数。*

### 单局运行并查看详细日志
如果你想查看一局完整游戏的详细行为日志（包括谁投了谁、为什么这么投、每晚死因等）：
```bash
uv run python scratch.py > game_log.txt
```
这会执行一局游戏，你可以打开生成的 `game_log.txt` 仔细分析玩家们的逻辑漏洞。

## 4. 各个角色的策略 (当前AI逻辑)

基于当前的代码库，各个角色的具体行动逻辑如下：

### 🐺 狼人 (Werewolf)
* **夜晚**：带有目标优先级的击杀。如果有明跳的预言家优先击杀（1000分），其次是金水（800分）、女巫（600分）、银水等。如果没有明确目标，则在好人中随机选择。
* **白天选举**：不参与竞选警长（不上警）。
* **白天发言**：假装平民，不跳任何身份。
* **投票**：**绝不互踩**（永远不会把票投给狼队友）。他们会潜伏在好人中，跟着当前场上的带头人（预言家、女巫、警长）一起冲票。由于狼人绝不互票，盲票阶段他们具有极大的存活优势。

### 🔮 预言家 (Seer)
* **夜晚**：在所有未验证身份的人中随机查验一个。避开已知的狼人和好人。
* **白天选举**：100% 参与竞选警长。
* **白天发言**：跳预言家身份，报出昨晚的查验结果（金水或查杀），并留**警徽流**（挑选两个未知玩家）。
* **投票**：优先投自己查验出的狼人；否则在未知玩家中盲选一个，并避开自己的警徽流和金水。
* **死亡移交**：死亡时，优先把警徽移交给警徽流里存活的第一顺位（此时全场自动认其为金水）。若警徽流里的人查出是狼，则撕毁警徽（全场自动认其为查杀）。

### 🧪 女巫 (Witch)
* **夜晚**：
  * **解药**：如果有人被杀且解药还在，100% 使用解药救人。
  * **毒药**：如果有毒药且解药已用，立刻在场上寻找“最像狼人”的人（认知评分最低的）进行毒杀。
* **白天发言**：如果救了人，会在遗言或发言中跳女巫身份并报出“银水”。
* **投票**：优先跟随预言家的号召。如果预言家死了，女巫会结合自己的认知评分盲选一个目标（避开金水和银水）来带队。

### 🔫 猎人 (Hunter)
* **白天行为**：默认不跳身份（除非迫不得已），发言假装平民。
* **投票**：严格遵循好人的“跟随顺位”（预言家 > 女巫 > 警长）。
* **死亡带人**：如果是正常死亡（被狼刀或被票决），会根据自己的认知评分，开枪带走最怀疑是狼人的玩家。

### 🃏 白痴 (Idiot)
* **白天行为**：发言和投票逻辑与平民、猎人完全一致，遵循“跟随顺位”。
* **放逐翻牌**：如果在白天被大家投票放逐，白痴会立刻翻牌免死，但他会从此失去投票权和被选举权。

### 🧑‍🌾 平民 (Villager)
* **认知更新**：每天仔细听别人发言，记住自称预言家的人、金水、银水、查杀和警徽流，并在发生警徽移交时更新信任表。
* **投票逻辑**：
  1. 优先跟随自己相信的 **预言家** 的号召。
  2. 如果预言家已死，其次跟随 **女巫** 的号召。
  3. 如果预言家和女巫都没有提供目标，最后跟随 **警长** 的号召。
  4. 走投无路时，根据自身评分逻辑投票（目前主要是随机投票，极易误伤好人）。
